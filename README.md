# VectorCalculator

## Калькулятор векторов

Программа предназначена для выполнения математических операций
с двумерными векторами.

## Возможности программы

- Сложение векторов.
- Вычитание векторов.
- Покоординатное умножение векторов.
- Скалярное произведение векторов.

## Алгоритм работы

1. Пользователь выбирает необходимую операцию.
2. Вводит два вектора в формате (x;y).
3. Программа извлекает координаты из строк.
4. С помощью оператора switch выбирается соответствующая функция.
5. Функция выполняет математическую операцию.
6. Программа выводит результат.

## Пример работы

Выберите операцию: 1

Введите вектора a и b: (1;2) (3;4)

Результат сложения:
c = (4;6)
